# Initial User Stories

## Administrator

- As an administrator, I want to manage CMS users so that access is controlled.
- As an administrator, I want to assign roles/permissions so that users only access permitted capabilities.
- As an administrator, I want audit visibility so that important actions are traceable.

## Editor

- As an editor, I want to create a draft so that content can be prepared before publishing.
- As an editor, I want to edit content in a rich editor so that I can structure an article.
- As an editor, I want AI assistance so that I can accelerate content preparation.
- As an editor, I want revision history so that I can understand content changes.
- As an editor, I want SEO fields so that articles are optimized for search.
- As an editor, I want to publish approved content so that readers can access it.

## Author

- As an author, I want to manage my permitted posts so that I can maintain my content.

## Reader

- As a reader, I want to browse published articles.
- As a reader, I want to search articles.
- As a reader, I want category/tag navigation.
- As a reader, I want useful metadata and fast page loading.
