# Definition of Done

A feature is Done when applicable criteria are satisfied.

## Product
- [ ] Requirements identified.
- [ ] Acceptance criteria satisfied.
- [ ] Out-of-scope behavior preserved.

## Engineering
- [ ] Architecture follows project standards.
- [ ] Validation implemented.
- [ ] Authorization implemented where required.
- [ ] Errors handled correctly.
- [ ] Observability added where useful.

## Testing
- [ ] Unit tests added/updated.
- [ ] Integration/API tests added/updated.
- [ ] Component tests added/updated when UI behavior changes.
- [ ] E2E tests added/updated for critical workflows.
- [ ] Regression tests pass.
- [ ] Coverage impact reviewed.

## Quality
- [ ] Typecheck passes.
- [ ] Lint passes.
- [ ] Build passes.
- [ ] No unnecessary dependencies introduced.
- [ ] No unrelated files changed.

## Documentation
- [ ] Requirements updated if needed.
- [ ] API docs updated if needed.
- [ ] Architecture/design docs updated if needed.
- [ ] ADR created/updated if needed.
- [ ] Operational documentation updated if needed.

## Review
- [ ] Code review completed.
- [ ] Security concerns reviewed.
- [ ] Known technical debt recorded.
