# oneCMS Development Workflow

Requirement
→ Clarification
→ Design
→ Implementation Plan
→ Implementation
→ Unit Tests
→ Integration/API Tests
→ Component Tests
→ E2E Tests
→ Code Review
→ Documentation
→ CI
→ Merge
→ Deployment
→ Verification

## AI-assisted development

Agents are allowed to accelerate implementation, but the engineering process remains
human-controlled.

Agents must use repository source-of-truth documents and must not invent requirements.

For significant changes, preserve an artifact trail:
- current task
- implementation plan
- test report
- review report
- handoff summary
